## Learning approach

Each project is developed through:
1. Problem framing and dataset understanding
2. Data quality investigation and exploratory data analysis
3. Data cleaning and feature engineering
4. Baseline modelling and model comparison
5. Evaluation, error analysis and improvement
6. Documentation and deployment
